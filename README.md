## 💻 Tech Stack & Features
- **Public Institutional Portal:** Academic course index, syllabus breakdown, fee structure, online admission enquiry form.
- **Student Portal:** Attendance check-in, fee receipts, digital study notes, on-demand online MCQ exams, downloadable & printable PVC student ID cards and scorecards.
- **Teacher & Admin Management Console:** Scoped faculty workspace, batch scheduling, MCQ & descriptive exam creator, paper evaluation & grading terminal, admission lead management.
- **Design:** Modern government-standard UI, high-contrast typography, Devanagari Hindi bilingual branding, full dark mode and accessibility support.

## 🚀 Running Locally
You can launch the platform locally using any static web server:

```bash
# Python 3
python -m http.server 8000

# Or with Node.js
npx serve .
```

Then open `http://localhost:8000` in your browser.
